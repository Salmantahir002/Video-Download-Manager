Project Overview & Goals

We will compile the Node.js backend, HTML/CSS frontend, yt-dlp.exe, and ffmpeg.exe into a single executable binary using the pkg packaging utility.

Core Problems we are Solving
  • Portability: Standard pkg binaries run on a virtual file system (/snapshot/...). However, Windows cannot execute native binaries (like yt-dlp.exe and ffmpeg.exe) directly inside a virtual filesystem. Solution: We will extract them to the local physical drive (%APPDATA%) automatically on startup.
  • Drive dependency: The original server assumes a D:\yt_dlp directory exists. If a user only has a C: drive, downloads will fail. Solution: We will default downloads to the user's standard Downloads/YT-Downloads directory.
  • Start ease: Instead of running a .bat file that needs Node.js pre-installed, users just run the .exe. The server launches and opens their web browser to the downloader interface automatically!

Why pkg?

Vercel's pkg compiles Node.js projects into self-contained executables including the Node.js runtime. This means the target laptops do not need Node.js or npm installed at all!

Size Optimization Advice

Your current FFmpeg folder includes ffplay.exe and ffprobe.exe, which together take up 420MB. By packaging only ffmpeg.exe, the final compiled executable stays down to ~264 MB instead of ~675 MB, making it much easier to distribute online.

Runtime Behavior

When someone runs yt-dlp-web.exe, it creates a hidden .yt-dlp-web folder in their home directory, extracts the executables there, and runs them. Subsequent runs are instant since the files are already unpacked!
